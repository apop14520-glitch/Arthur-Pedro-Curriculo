# AGENTS.md

## Objetivo

Este projeto é o portfólio profissional de Arthur Pedro, Chefe de TI, com posicionamento em Infraestrutura, Cloud Computing, Governança e Gestão de Tecnologia.

## Tecnologia

- Vite
- JavaScript puro (ES Modules)
- CSS puro
- Sem React, frameworks de UI ou dependências de produção

## Direção visual

Manter o visual dark premium: azul profundo, ciano como destaque, tipografia Space Grotesk/DM Sans, linhas técnicas, alto contraste, animações discretas e bastante espaço. Evitar estética genérica de hacker, excesso de brilho e componentes que pareçam um painel administrativo.

## Conteúdo

Preservar o foco em liderança técnica e infraestrutura. Tecnologias prioritárias: Proxmox, Zabbix, GLPI, Active Directory, File Server, Windows/Linux, ERP, redes, CFTV, rádio, fibra óptica e switches.

Não inventar números, resultados, datas, empregadores, certificações, e-mails ou links. Quando faltarem dados, manter marcadores explícitos para o usuário preencher. Projetos devem ser descritos como áreas de atuação até que existam estudos de caso e métricas confirmados.

## Regras de alteração

- Manter acessibilidade por teclado, contraste e suporte a `prefers-reduced-motion`.
- Testar as larguras desktop, tablet e mobile.
- Não trocar JavaScript puro por React sem solicitação explícita.
- Manter os links externos centralizados no objeto `profileLinks` em `src/main.js`.
- Executar `npm run build` antes de entregar mudanças.
